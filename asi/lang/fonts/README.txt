The CJK letters of the OpenRR menu (zh-CN / ja / ko) need a font with those letters.
Put NotoSansCJKsc-Regular.ttf into this folder (the OpenRR language pack, SIL Open Font
License 1.1 - see Noto-CJK-LICENSE.txt). Without it the Windows CJK fonts (msyh.ttc /
simhei.ttf) are used, and if none of them has the letters the menu stays English.
