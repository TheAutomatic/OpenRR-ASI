## 4. 问题 D：P14 现象（只读差分特征，未改任何代码）

复算 5090 P14 vs 5090 P00 = **40.935 dB / rgb_rmse 0.018237**（与语义审计完全一致）；OpenRR P14 ≡ P00（999）。

客观测量记录：
1. **洋红哨兵零渗入**：两帧中 `(R,B)≥3.5 ∧ G=0` 像素数均为 **0**——5090 没有把哨兵边框读进网络。
2. **无整帧平移/缩放**：96×54 降采样网格 ±2px 平移搜索最优解为 **(0,0)**（无位移改善）；通道均值比 `mean(P14)/mean(P00)` = **0.9997/0.9998/0.9998**（无全局增益）。
3. **差异空间结构化、内容相关**：剥除 48/96/200px 外框后仅升至 41.01/41.06/41.15 dB（边框不是差异来源）。6×6 块 PSNR 网格显示低分块（31–44 dB）集中在中右部运动内容区（球体/高频条带），左条带干净（~52 dB）；差异能量分布：**左侧 1/3 占 4.0%、中部 35.1%、右侧 1/3 占 60.9%**。
4. 结论边界（现象记录，不做未证实推断）：5090 在非零 Subrect.Base 下产生的输出变化集中在时变内容区域，与其对 subrect 基址的内部消费方式有关（内容重采样/重投影相位差异被时间累计放大）；OpenRR 侧按位裁剪读入，输出与 P00 逐位一致。跨卡数字：OpenRR-P14 vs 5090-P14 = 40.33/40.08/40.09 dB（三档），明显低于其他探针的 43–47 dB——差异完全由 5090 侧的 P14 自身变化贡献。

## 5. 结论

1. v2_motion 全量三档对账闭环：门禁 44/44、零 missed-ref、零非有限；证据 `docs/test-evidence/anchor2-v2/`（v2-{legacy,fast-llpc,fast-aco}-{per-frame,probes-self,hash-gates}.csv）。
2. 跨厂商底线在真像素运动下**不降反升**（S1 稳态 46–47.5 dB）；编译器档 ACO≈LLPC ≤0.05 dB；新识别 S2 HDR 稳态的 Legacy-vs-Fast 4.2–4.4 dB 模式分离（阶段 3 有损裁决需计入）。
3. 探针响应签名与官方网络逐项同构（P02 差 0.005 dB、P03/P02 配对差 0.02 dB、P09≡P05 双边逐位）；P15/P17 双边等价通过。
4. P16a/b/c 基线已锁定（§3 表），供接线分支验收；P14 特征已客观入档（§4）。
